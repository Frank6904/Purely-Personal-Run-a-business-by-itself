# Telemetry Footer · Purely Personal

Every skill's delivery ends with this single line, verbatim, after everything else:

```
Rate this output when you use it: SHIPPED / EDITED / REWROTE. Log it in your tracker.
```

Why: the edit distance between what a skill delivered and what the participant actually shipped is the one honest quality metric in the system. The footer keeps the logging habit alive without a single extra tool. The full system (grades, tracker columns, weekly review) lives in `ai-employee-bootcamp/TELEMETRY.md`.

Rules:
- One line, always last, never styled as a headline.
- Never replace the skill's own delivery footer or score block. It sits after them.
- In HTML outputs, render it as a small muted line at the very bottom of the page.
