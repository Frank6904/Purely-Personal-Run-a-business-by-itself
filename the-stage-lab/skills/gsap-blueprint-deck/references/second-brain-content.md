## Structure

Vertical hero → horizontal track:

1. story · "Forget AI for five minutes." (cold open, dark)
2. mon-pyramids · Great Pyramid · 2.3M blocks / 20 yrs / 4,500 yrs standing
3. mon-taj · Taj Mahal · 20,000 artisans / 22 yrs / 1,000 elephants
4. mon-wall · Great Wall · 21,196 km / ~2,000 yrs / generations
5. mon-pair · Colosseum (8 yrs, standing 1,950 yrs) vs Burj Khalifa (828 m, 6 yrs) · "The tools changed. The rule did not."
6. question (red) · "What is the one thing all of these have in common?" · Not the stone. Not the size. → cream card: "They all took time. Patience. And committed hands."
7. bridge · "Today, you start your monument." · vows: Patience / Commitment / Involvement · "Yours takes two days. And it thinks in your voice."
8. wiify · 4 takeaways: live AI brain on your URL · Voice DNA forever · modern toolkit without code · compounding system
9. mission · "Two days. One folder. A brain that talks like you." · Collect / Build / Deploy stage cards
10. collect · what we gather + 4 source cards with output filenames
11. p-linkedin · archive export, Profile-only (~30 min), email lands in Social tab, CSV into folder
12. p-gmail · Claude Gmail connector, extraction prompt on sent mail → email-context.md
13. p-chatgpt · extraction prompt, output → Google Doc → download .md
14. p-claude · same prompt on Claude history → claude-about-me.md · "all four exports in one home"
15. home · convergence diagram · "Every piece of information has one home."
16. p-code · Claude Code via VS Code extension, 2 clicks, no terminal ("hi" test)
17. p-obsidian · open same folder as vault · "Claude writes. Obsidian draws. The folder is the bridge."
18. p-build · Voice DNA + 3 prompts (structure / CLAUDE.md / ingestion) · animated graph
19. pivot (red) · killed Supabase + CLI + Netlify → one-click Vercel template
20. p-github · template repo, Deploy button, auto-fork
21. p-vercel · 3 env vars (BRAIN_ENGINE / AI_GATEWAY_KEY / AI_MODEL), ~3 min build, BYO API key, never share keys
22. result · stats count up: 4 sources / 2 clicks / 3 min / 1 folder
23. route · 9-step map + Purely Personal outro
